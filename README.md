# Dragonlance Moons

**Unofficial Fan Content for Foundry Virtual Tabletop and the Advanced Roleplaying System (ARS)**

Dragonlance Moons is a free, unofficial Foundry Virtual Tabletop module for the **Advanced Roleplaying System (ARS)**.

The module implements the three-moon magic system and the **Wizard of High Sorcery** rules used in classic Dragonlance roleplaying, including lunar phases, lunar alignments, bonus spell slots, saving throw modifiers, and effective caster level adjustments.

## Features

### Three Moons

The module tracks:

* **Solinari**
* **Lunitari**
* **Nuitari**

Each moon follows its own orbital cycle.

The Game Master can configure and adjust the moons, while the module tracks their movement using Foundry's world time.

### Wizard of High Sorcery

The module provides a separate **Wizard of High Sorcery** class for ARS.

The class includes:

* White Robe
* Red Robe
* Black Robe
* Lunar patron
* Wizard of High Sorcery level progression
* Spell progression
* Lunar spell bonuses
* Lunar saving throw modifiers
* Effective arcane caster level modifiers

The Robe selection becomes available at **3rd level**.

Lunar mechanical effects begin at **4th level**, according to the implemented rules.

### Lunar Magic

The module implements the effects produced by:

* Waxing
* High Sanction
* Waning
* Low Sanction
* Lunar alignments
* Three-moon alignment / Night of the Eye

Bonus spells are added as real ARS arcane spell slots. The player can choose which spell levels receive the available bonus slots.

Effective Level modifiers affect applicable spell scaling through ARS without increasing the wizard's actual class level, spell progression, hit points, THAC0, experience, or other level-based progression.

## What is NOT implemented

The following rules are intentionally outside the scope of this module:

* Test of High Sorcery
* Changing Orders and its associated penalties
* Automated forbidden-school restrictions
* Name Spell restrictions
* Renegade Wizard rules

These can be handled manually by the Game Master when necessary.

## Requirements

You need:

1. **Foundry Virtual Tabletop**
2. **Advanced Roleplaying System (ARS)**

ARS is a separate project and is not included with this module.

## Installation

### Automatic installation

If the module is available through the Foundry package browser, install it from:

**Add-on Modules → Install Module**

Search for:

**Dragonlance Moons**

### Manual installation

Download the latest release ZIP from the GitHub Releases page.

Extract the module into:

`FoundryVTT/Data/modules/`

The resulting folder should be:

`FoundryVTT/Data/modules/dragonlance-moons/`

Then start Foundry and enable the module in your world.
