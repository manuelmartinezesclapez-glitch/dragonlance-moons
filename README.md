# Dragonlance Moons

**Unofficial Fan Content for Foundry Virtual Tabletop and the Advanced Roleplaying System (ARS).**

Dragonlance Moons is a free, unofficial Foundry Virtual Tabletop module for the Advanced Roleplaying System (ARS).

It implements the three-moon magic system and Wizard of High Sorcery rules used in classic Dragonlance roleplaying, including lunar phases, lunar alignments, bonus spell slots, saving throw modifiers, and effective arcane caster level adjustments.

## Features

- Solinari, Lunitari and Nuitari lunar tracking.
- Independent orbital cycles for the three moons.
- GM controls for moon positions.
- Player lunar display.
- Wizard of High Sorcery class.
- White, Red and Black Robes.
- Lunar phase modifiers.
- Lunar alignment modifiers.
- Bonus arcane spell slots chosen by the player.
- Effective arcane caster-level modifiers.
- Night of the Eye / three-moon alignment.

## Intentionally not automated

The following rules are outside the scope of this module and are left to the Game Master:

- Test of High Sorcery.
- Changing Orders and associated penalties.
- Forbidden-school restrictions.
- Name Spell restrictions.
- Renegade Wizard rules.

## Requirements

- Foundry Virtual Tabletop v14.
- Advanced Roleplaying System (ARS).

ARS is a separate project and is not included with this module.

## Installation

Download the latest release ZIP from the GitHub Releases page and extract the `dragonlance-moons` folder into:

`FoundryVTT/Data/modules/`

The final path should be:

`FoundryVTT/Data/modules/dragonlance-moons/module.json`

Then start Foundry and enable **Dragonlance Moons** in your world.
